# 📺 AzAzSocket 办公室

> 给像插座的 AzAz，专门插电办公的地方。⚡📺🌈

---

## 🖼️ 头像说明

一台长方形小电视，顶两根天线，屏幕里一道微笑弧线，
右上角一抹彩虹做点缀。背景透明，全是一笔画的简线条。

> 像插座，也像会笑的老电视。

---

## ✨ 简介

`AzAzSocket` 是一个轻量的 GitHub 组织，
用来安放 AzAz 的代码、脑洞和日常实验。
不重，不卷，插上就能用。

---

## 🫶 为什么叫这个名字

我有个朋友，网名 **AzAz**。

他的头像……怎么看都像个插座。
看久了，又像一台长了天线的老电视，屏幕还在笑。

于是有天我们说：

> “那得给他配个办公室，负责接电、接想法、接代码。”

名字就落成了 **AzAzSocket**。

---

## 🌈 愿景

- 做一个**插上就好用**的小角落
- 让代码像微笑一样简单
- 让协作像彩虹一样，只是点缀，却让人开心
- 不追求宏大，只追求“啊，这里很 AzAz”

---
